# Bronx PrEPreach

This repository contains materials for our multipage research website built with HTML, CSS, and JavaScript.

## Publish on GitHub Pages

1. Upload `index.html`, `about.html`, `research.html`, `taskforce.html`, `meetings.html`, `modeling.html`, `publications.html`, and the **folders** `css` and `js` to the root of your existing repository. Preserve the folder structure.
2. Commit changes to your default branch.
3. In **Settings → Pages**, choose **Deploy from a branch**, select your default branch (often `main`) and **/(root)**, and save.
4. Wait for the Pages deployment to finish, then reload your existing site URL.

The old README and `_config.yml` can remain. GitHub Pages serves `index.html` as the homepage when it is present. If an existing Jekyll theme changes the HTML appearance, create an empty `.nojekyll` file in the repository root.

## Edit

- Page text: edit the relevant `.html` file.
- Colors, fonts, and spacing: `css/style.css`.
- Mobile menu: `js/script.js`.
- Replace clearly marked placeholders with approved project information.

No paid hosting, framework, or build step is required.
