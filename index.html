Our project aims

Three aims. One shared goal.

AIM 1

Build & Validate

Build and validate a system dynamics model of key factors impacting PrEP reach in the Bronx.

Learn more →
AIM 2

Identify & Evaluate

Use the model to identify and evaluate high-impact strategies to improve PrEP reach.

Learn more →
AIM 3

Pilot Implementation

Pilot implementation of the highest-potential PrEP engagement strategies identified in Aim 2.

Where we are now

From modeling to implementation

Current phase: R33

Putting community-informed insights into practice

Building on model development and strategy evaluation in the R21 phase, the R33 phase focuses on developing and piloting a program designed to increase PrEP reach in the Bronx.
